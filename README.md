# Prajwal Gujar — DevOps Portfolio

A responsive, static DevOps portfolio built with HTML, CSS and vanilla JavaScript. It is designed for GitHub Pages and does not require a build step.

## Before publishing

1. Review `index.html` and update the name, email, LinkedIn and GitHub links if needed.
2. Replace the three `https://github.com/` project links with your own project repository URLs.
3. Add a resume PDF if you want a downloadable resume link. Update the page with the correct file path.
4. Make sure all project descriptions accurately reflect your actual work and skills.
5. Preview locally by opening `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a GitHub repository named `devops-portfolio` (or another name you prefer).
2. Upload all files and folders from this project to the repository root. Ensure `index.html` is at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the deployment to finish. Your site should be available at:

   `https://YOUR-GITHUB-USERNAME.github.io/devops-portfolio/`

For a user/organization site at `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly `YOUR-GITHUB-USERNAME.github.io`.

## Contact form note

This is a static website. GitHub Pages does not execute PHP or other server-side code. The contact section uses an email link; if you add a form later, connect it to a third-party form service or your own backend.

## Resume download

The supplied resume PDF is stored at `assets/Prajwal_Gujar_DevOps_Resume.pdf` and is linked from the home and contact sections. Replace that file when you update your resume, keeping the same filename or updating the links in `index.html`.

## Customize

- Main content and links: `index.html`
- Colors, layout and responsive design: `styles.css`
- Mobile navigation: `script.js`

## Resume-aligned content

The portfolio includes the professional roles, dates, tools, project themes, stated outcome metrics and education shown in the supplied resume. Review all figures and wording before publishing to make sure they remain accurate.
